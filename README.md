## 🚀 Despliegue y Ejecución Local

### Requisitos
- [Node.js](https://nodejs.org/) (versión 18 o superior).

### Instrucciones
1. Clona el repositorio:
   ```bash
   git clone https://github.com/TU-USUARIO/neural-media-house.git
   cd neural-media-house
   ```
2. Inicia el servidor local:
   ```bash
   node server.js
   ```
3. Abre tu navegador en `http://localhost:3000`.

*Opcionalmente, puedes abrir directamente el archivo standalone `neural_media_house.html` con doble clic para navegación sin servidor.*
